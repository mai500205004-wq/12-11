## Brand & Style

This design system establishes a high-performance, experimental design architecture engineered for advanced neural intelligence research, lateral cognitive mapping, and computational avant-garde incubation. 

### Aesthetic Philosophy
The system synthesizes **Cyber-Kinetic Avant-Garde** with **Tactical Scientific Brutalism**:
- **Obsidian Monolith Foundation:** Interfaces exist in high-density void spaces, evoking classified deep-tech instrumentation and quantum hardware terminals.
- **Phosphor Synapse Visuals:** Active computation is rendered through high-saturation, radioactive chromatic signals (volt green and phosphor cyan) that pierce the monochromatic void.
- **Architectural Precision:** Every module operates with millimeter calibration. Visual tension is achieved via asymmetric precision grids, structural metadata overlays, crosshairs, and engineered border intersections rather than ornamental decoration.
- **Kinetic Feedback:** State changes evoke mechanical and optical sensors—crisp micro-latencies, phosphor trails, and modular hardware interlocking.

## Colors

The palette leverages absolute tonal polarity to convey an elite research environment operating in ambient darkness.

### Roles & Semantic Allocation
- **Canvas Base (`#090B10`):** The deep obsidian baseline. Zero ambient light, absorbing light to elevate interface legibility and reduce ocular fatigue during deep-phase analysis.
- **Surface Elevation Series:**
  - `surface-base`: `#090B10` (Root frame)
  - `surface-elevated`: `#0E121A` (Docked panels, card foundations)
  - `surface-overlay`: `#141A24` (Hover states, contextual command HUDs, active workspace nodes)
  - `surface-terminal`: `#040507` (Recessed logs, command prompts, deep telemetry sinks)
- **Primary Energy (`#10F984` — Radioactive Chartreuse):** Primary interaction signal, authorized operations, active neural networks, real-time quantum synthesis, confirmed lateral paths.
- **Secondary Co-Pilot (`#00F0FF` — Cyan Phosphor):** System diagnostics, secondary vector axes, contextual parameters, neural synchrony indicators.
- **Tertiary Alert (`#FF3B5C` — Kinetic Crimson):** Neural overload thresholds, parameter destabilization, classified readouts, system interrupts.
- **Structural Chrome & Boundaries:**
  - `border-structural`: `rgba(255, 255, 255, 0.08)` (Micro-hairlines, frame containers)
  - `border-interactive`: `rgba(16, 249, 132, 0.35)` (Focus rings, armed targets, precision brackets)
  - `text-primary`: `#F2F5F9` (Primary telemetry, high-contrast labels)
  - `text-secondary`: `#8A93A6` (Metadata, parameters, non-essential tracking readouts)
  - `text-tertiary`: `#424957` (Inactive timestamps, grid index tokens)

## Typography

The typography strategy implements a strict functional triage:

- **Display & Headlines (`Space Grotesk`):** Industrial, geometric, slightly eccentric modernism. Engineered letterforms establish an institutional, experimental presence in large formats.
- **Body & Long-form Logic (`Plus Jakarta Sans`):** Neutral, hyper-legible geometric clarity that counterbalances the tension of monospace parameters and display titles. Provides effortless readability across detailed research briefs.
- **Instrumentation & Metrics (`JetBrains Mono`):** Zero-ambiguity tactical character generation. Utilized for data coordinates, machine-state metrics, raw lateral parameters, and metadata chips.
- **Styling Rules:** All `label-caps` must be rendered uppercase with expanded tracking (`0.14em`) to mirror aerospace avionics and laboratory telemetry tags.

## Layout & Spacing

The layout model is governed by an **Architectural Modularity Grid** simulating surgical scientific instrument consoles:

### Layout Rhythm & Fluid Grid
- **Desktop (>= 1280px):** 12-column rigid fluid grid with `1.5rem` gutters and `3.5rem` minimum canvas margins. Content panels snap directly to coordinate lines.
- **Tablet (768px – 1279px):** 8-column layout with `1.25rem` gutters and `2rem` margins. Side intelligence decks collapse into expandable HUD trays.
- **Mobile (< 768px):** 4-column layout with `1rem` margins and `1rem` gutters. Stacks vertically along an explicit continuous tactical border timeline.

### Spacing Guidelines
- Micro-spacing (`space-xs`, `space-sm`) governs tightly-coupled metrics, bounding box brackets, and diagnostic badge internals.
- Structural layout gaps (`space-lg`, `space-xl`, `space-2xl`) separate distinct operational pods (e.g., separating the Inception Canvas from the Neural Synthesis Engine).
- Vertical rhythm strictly references `0.25rem` base increments to maintain baseline alignment across dual-column data arrays.

## Elevation & Depth

This system avoids soft skeuomorphic shadows or diffuse consumer elevation models. Depth is established through **Architectural Tiers, Precision Ghost Hairlines, and Phosphor Photoluminescence**:

### Elevation Hierarchy
1. **Tier 0 (The Deep Void - `#090B10`):** Canvas backdrop. Imprinted with an ultra-faint optical micro-grid (`rgba(255, 255, 255, 0.02)` at 24px cell intervals).
2. **Tier 1 (Structural Panels - `#0E121A`):** Hard perimeter containment via `1px solid rgba(255, 255, 255, 0.08)`. Zero baseline drop shadow.
3. **Tier 2 (Armed / Active Modules - `#141A24`):** Elevated state triggered by user engagement or active synthesis cycles. Highlighted by an illuminated edge border (`1px solid rgba(16, 249, 132, 0.4)`).
4. **Tier 3 (Floating HUD / Overlays):** Translucent backdrop surface (`rgba(14, 18, 26, 0.88)` with `backdrop-filter: blur(16px)`), bounded by `1px solid rgba(0, 240, 255, 0.3)`.

### Chromatic Glow & Lateral Quantum Pulse
- Optical emphasis relies on directional phosphor halation rather than dark drop shadows:
  - **Chartreuse Glow:** `0 0 20px rgba(16, 249, 132, 0.18), 0 0 1px rgba(16, 249, 132, 0.6)`.
  - **Cyan Pulse:** `0 0 24px rgba(0, 240, 255, 0.16), 0 0 1px rgba(0, 240, 255, 0.5)`.
- **Quantum Lateral Pulse Effect:** Used selectively on active neural processing nodes and the "Locked Brief Box." Emits a localized, 1.5Hz respiratory harmonic ring that scans horizontally across the card boundary using a masked CSS linear gradient.

## Shapes

The geometric vocabulary is **Strict Industrial Sharpness (`roundedness: 0`)**:

- **Zero Curvature Archetype:** All standard boundaries, button containers, data logs, and window partitions feature absolute `0px` border-radii. This reinforces a hardened laboratory instrument look.
- **Chamfered Cuts (Tactical Notches):** Critical action anchors and premium brief cards may feature 45-degree angled corner cuts (`clip-path: polygon(...)`) measuring `8px` or `12px` on the top-right or diagonal-opposing corners.
- **Corner Brackets:** Interactive containers utilize technical framing overlays: microscopic L-shaped corner notches (`4px × 4px`) positioned on container edges to indicate mechanical docking points.

## Components

### 1. Primary Action & Kinetic Buttons
- **Base Geometry:** Sharp rectangles (`roundedness: 0`), uppercase `label-caps` typography, internal padding `0.75rem 1.5rem`.
- **Primary Kinetic State (Radioactive Lime):**
  - Surface: `#10F984` solid with `#090B10` bold text.
  - Hover: Instant zero-latency shift to `#00F0FF` background accompanied by a micro-translation (`translate(-2px, -2px)`) and a hard-edged structural drop line `2px 2px 0px #10F984`.
- **Ghost Tactical State:** Transparent background, `1px solid rgba(255, 255, 255, 0.2)` border, text `#F2F5F9`. Hover activates primary lime border with an internal glow fill (`rgba(16, 249, 132, 0.06)`).

### 2. Status Chips & Telemetry Tags
- **Structure:** `JetBrains Mono`, `0.6875rem`, uppercase, vertical alignment centered.
- **Composition:** Bounded by `1px solid rgba(255, 255, 255, 0.12)`, background `#0E121A`, padding `0.25rem 0.5rem`.
- **Indicator:** Prepended by a 4px flashing geometric square (Green `#10F984` for ONLINE/SYNTHESIZING, Cyan `#00F0FF` for QUANTUM_STANDBY, Red `#FF3B5C` for CRITICAL_DRIFT).

### 3. Precision Diagnostic Data Lists
- **Structure:** Monospaced table-matrix architecture. Alternating rows with faint surface step (`#090B10` to `#0B0F16`).
- **Dividers:** Hairline borders `1px solid rgba(255, 255, 255, 0.04)`.
- **Key-Value Realignment:** Left column features dimmed technical keys in `text-secondary`; right-aligned values set in `mono-code` `#F2F5F9` with real-time decimal stabilization.

### 4. Input Terminals & Parameter Fields
- **Container:** Dark terminal well `#040507`, sharp edges, `1px solid rgba(255, 255, 255, 0.1)`. Padding `0.875rem 1rem`.
- **Typography:** `JetBrains Mono` body text with high contrast `#F2F5F9`. 
- **Focus State:** Border shifts instantaneously to `#10F984`, accompanied by an exterior single-pixel neon aura (`box-shadow: 0 0 10px rgba(16, 249, 132, 0.2)`). Carat is a non-blinking solid green block (`#10F984`).
- **Prompt Adornment:** Prefixed with tactical indicator glyphs (`//` or `>>`) in dimmed chartreuse.

### 5. Checkboxes, Toggles & Radio Arrays
- **Checkboxes:** Exact `16px × 16px` sharp squares, border `1px solid rgba(255, 255, 255, 0.3)`. Checked state displays a solid fill of `#10F984` with a black `#090B10` sharp cross/check mark.
- **Radio Nodes:** Outer `16px × 16px` sharp square with nested concentric sharp square dot (`6px × 6px`) in neon cyan `#00F0FF`.
- **Toggle Switches:** Hard rectangular split-block sliding track (`36px × 18px`), mechanical slide transition with immediate response (100ms cubic-bezier(0, 0, 0.2, 1)).

### 6. Cards & Deep-Phase Research Panels
- **Structure:** Surface `#0E121A`, sharp corners, structural outer border `rgba(255, 255, 255, 0.08)`.
- **Diagnostic Header:** Integrated top telemetry rail featuring system serial numbers (e.g., `SEC_04 // LATERAL_NODE`), card status, and coordinate crosshairs (`+`) rendered in the four card corners.

### 7. Bespoke System Component: "The Locked Brief Box"
- **Purpose:** Secure quarantine module for high-order creative briefs undergoing lateral neural synthesis.
- **Physical Spec:** Heavy structural module set in `#07080D` canvas, framed by an intermittent perimeter dashed neon line (`#00F0FF` / `#10F984`).
- **Quantum Lateral Pulse:** An animated horizontal scanline (`2px` height, gradient of transparent to `#10F984` to `#00F0FF` to transparent) traverses top-to-bottom across the brief surface on a continuous 4-second sweep.
- **Telemetry Padlock Indicator:** Center-stamped geometric lock mechanism surrounded by dynamic rotating monospace degree ticks (`00°`, `90°`, `180°`, `270°`) denoting cognitive decryption readiness.
